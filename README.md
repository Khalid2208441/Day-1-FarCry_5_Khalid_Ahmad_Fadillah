## Deskripsi Singkat
Repository ini berisi dokumentasi kegiatan workshop, yaitu rangkuman materi, poin penting, dan pendapat pribadi.

## Tujuan Repository
Repository ini dibuat untuk mengumpulkan dokumentasi kegiatan workshop, seperti materi yang disampaikan dan catatan pembelajaran selama workshop berlangsung. Diharapkan GitHub dapat dimanfaatkan sebagai media penyimpanan, pengelolaan, dan publikasi dokumentasi proyek secara daring.

## Informasi Workshop
Workshop berjudul From AI to GitHub: Building with AI, Managing Change with GitHub, dengan pemateri Nugi Farhan. Topiknya adalah prompt engineering serta manajemen perubahan dengan Git dan GitHub. Praktiknya membuat aplikasi web sederhana bernama Student Task Planner.

## Rangkuman Materi
- Prompt engineering: prompt yang baik terdiri dari Role (peran AI), Task (tugas), Context (kebutuhan dan batasan), dan Format (bentuk keluaran). Semakin spesifik prompt, semakin baik hasilnya.
- Git dan GitHub: Git adalah sistem version control untuk melacak perubahan file, sedangkan GitHub adalah platform untuk menyimpan repository secara daring dan berkolaborasi. Alur kerjanya working directory, staging area, lalu repository.
- Perintah dasar: git init, git add, git commit, git push, git pull, dan git clone.
- Kurikulum OBE 2026 D4 Teknik Informatika: 8 semester, 49 mata kuliah, 145 SKS. Kurikulum disusun dari profil lulusan ke CPL, lalu ke mata kuliah. Semester 7 dan 8 untuk magang dan tugas akhir.
- CPL: terdapat 11 CPL. CPL 6 (komunikasi dan kerja tim) paling dibutuhkan dunia kerja.
- MBKM dan MSIB: mahasiswa dapat belajar di luar program studi, misalnya magang bersertifikat, dan kegiatannya dikonversi hingga 20 SKS.
- Roadmap JTIK 2026-2030: visi menjadi jurusan bertaraf internasional di bidang informatika dan komputer.


## Pendapat tentang Workshop
Workshop ini sangat bermanfaat karena menggabungkan pemanfaatan AI untuk membangun sesuatu dengan pengelolaan hasilnya melalui Git dan GitHub. Konteks yang jelas dalam prompt menentukan kualitas hasil AI, dan pemahaman alur Git membuat version control lebih mudah dipahami.
